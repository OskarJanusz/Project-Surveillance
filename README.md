# Project: Surveillance
## Description
**"Project: Surveillance"** is text-based game inspired by **G. Orwell's "1984"** and **"Beholder" game series**. Player is Network Overseer working in IT Department of The Ministry. His job is to monitoring citizens and managing servers. Project is developed by me to improve my skills in Bash scripting.
## System requirements
- Windows 11 / Ubuntu 20.04 or newer / macOS Sequoia 15 or newer
- Bash 5.0 or newer
## Startup guide
Download project from GitHub repository and unpack it. Make **project_surveillance.sh** executable - you can do it on Linux distro using this command:
```bash
chmod +x project_surveillance.sh
```
Then, to open project, you need to open your terminal and type:
```bash
./project_surveillance.sh
```
